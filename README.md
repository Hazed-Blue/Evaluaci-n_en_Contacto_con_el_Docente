# Sistema de Cajero Bancario Automático 

Este repositorio contiene el desarrollo del Proyecto Integrador correspondiente a la **Evaluación en Contacto con el Docente** del primer semestre de la asignatura **Lógica de Programación**.

## Objetivo del Sistema
El objetivo de este proyecto es analizar, diseñar e implementar una solución de software que simule las operaciones esenciales de un Cajero Automático. El sistema busca garantizar un entorno seguro y controlado mediante estructuras de control para que el usuario interactúe con su saldo financiero de forma intuitiva a través de la consola.

## Descripción de Funcionalidades
El software cuenta con cuatro módulos lógicos principales mapeados con nuestros diagramas de flujo:
1. **Módulo de Autenticación:** Valida la identidad del usuario mediante un PIN de 4 dígitos con un límite de 3 intentos.
2. **Consulta de Saldo:** Muestra de forma inmediata los fondos disponibles en la cuenta.
3. **Depósito de Efectivo:** Permite sumar montos positivos al saldo actual.
4. **Retiro de Efectivo:** Evalúa de forma condicional si existen fondos suficientes antes de realizar el débito y actualizar la cuenta.
